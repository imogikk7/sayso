# Перед съёмкой: что проверить на телефоне

Пройди сверху вниз на iPhone, на котором будешь снимать. Отмечай ✅ / ❌. Если что-то ❌, напиши, что именно видишь.

## 1. Установка и вид
- [x] Иконка на рабочем столе: SAY по центру как на образце, «So» целое. Если старая — перезагрузи телефон (iOS кэширует иконки).
- [x] Заставка: сначала просто SAY, потом перо пишет «So» (хук S → верх → угол → середина → хвост → o → росчерк). Без мелкого текста.
- [x] Онбординг (появится только на «чистой» установке; можно пропустить): 3 экрана, кнопки Continue / Get started.
- [x] Светлая и тёмная тема: Настройки → Экран и яркость → переключи и пройди все 4 вкладки. Нигде нет невидимого текста.

## 2. Чат
- [x] Шапка: аватар S, «SaySo», «writes as Me · Telegram».
- [x] Приветствие SaySo и кнопки Message / Email / Essay / Series / Rewrite / Reply. Тап по кнопке меняет меню над полем.
- [x] **Write → Message**, «To Friends»: «скажи Мире что опоздаю на 20 минут» → ответ — это сообщение Мире, а не «скажи Мире…».
- [x] 👎 → чипы причин → «Too long» → новый, более короткий ответ; иногда тост «✨ Learned: …».
- [x] ✏️ → своя версия → Save → копируется, тост.
- [x] Альтернативы под ответом (пунктирные пузыри): тап копирует.
- [x] **Rewrite**: вставь черновик → ответ в твоём стиле.
- [x] **Reply**: вставь чужое сообщение (кнопка Paste слева) → твой ответ.
- [x] **Write → Email**: «попроси профессора перенести защиту на четверг» → тема (Copy subject) + письмо, без сленга.
- [x] **Reply → Email**: вставь письмо → ответ на него.
- [x] **Write → Essay**: вопрос сверху, «About 250 words», заметки голосом → эссе + «Make it stronger: answer one» → ответь голосом → доработанное эссе.
- [x] **Series**: ответ из нескольких сообщений.
- [x] 🎙 Голос: скажи фразу 5–10 секунд по-русски, потом по-английски. Текст без повторов слов и без «..» в конце, имена с большой буквы. Если «криво» — запиши, что сказал и что получилось.

## 3. Стили
- [ ] Карточка «93% sounds like you» без «So» на фоне, полосы SaySo 93% / Generic AI 69%.
- [ ] «By kind of text»: Messages показывает число сообщений (9168), не «Not yet». Emails / Essays — число или «Teach me».
- [ ] «By who you're talking to»: карточки Partner / Friends / Family / Elders, тап открывает стиль.
- [ ] Переключатель стиля (пилюля «Me · Telegram»): список стилей, «New style from chats…», «Add emails», «Add essays».
- [ ] Добавить письма: скриншоты 2–3 своих писем → число Emails растёт.
- [ ] (Для сцены 3 видео) создать стиль из экспорта WhatsApp: «Which one is you?» → этапы → самопроверка → Use this style. Занимает несколько минут — сделай заранее.

## 4. Клавиатура (в Telegram)
- [ ] Настройки → Основные → Клавиатура → Клавиатуры → SaySo добавлена, **Полный доступ** включён.
- [ ] В Telegram 🌐 → SaySo. Новый вид: клавиши с тенью, светящаяся ✨.
- [ ] Набери черновик своими клавишами → ✨ → 1–3 варианта → тап вставляет вместо черновика.
- [ ] Формат Series → ✨ → стопка → тап вставляет часть 1 → отправь → «Next» → часть 2.
- [ ] Чип аудитории: AI подсказывает (иконка ✨), можно сменить.
- [ ] Вкладка Keyboard в приложении: превью клавиатуры меняется от настроек; «Learn from what I type» включи для съёмки.

## 5. Back Tap (шорткат) — главное, что раньше не работало
- [ ] Установи шорткат кнопкой в приложении: вкладка «Настройки» → шаг 3 → **«Добавить команду SaySo»** → в «Командах» нажми «Добавить команду». Собирать вручную не нужно (ручная сборка спрятана под «Собрать самому»).
- [ ] Настройки iPhone → Универсальный доступ → Касание → Касание задней панели → Двойное касание → добавленная команда SaySo.
- [ ] В приложении включи переключатель «Настроено» — шаг 3 отмечается ✓.
- [ ] В чате Telegram с открытой клавиатурой SaySo: двойной тап по спине → «Who is it for?» → Friends → заметка или пусто → ждёшь 6–10 с.
- [ ] Шорткат показывает ответы и пишет «Switch to the SaySo keyboard…».
- [ ] Клавиатура SaySo **сама** показывает «Replies from your screenshot» (в течение 1–2 с; если клавиатура была закрыта — открой её). Тап по ответу → он в поле ввода → Send.
- [ ] Повтори 2 раза подряд — второй раз тоже приходит.
- [ ] Если ответы не появились в клавиатуре: проверь Полный доступ; закрой и открой клавиатуру (🌐). Напиши мне, что видишь.

## 6. Настройка (вкладка Setup)
- [ ] Кольцо прогресса показывает, сколько шагов сделано; шаги отмечаются ✓ после настройки клавиатуры и Back Tap.
- [ ] Кнопка тестового запроса отвечает.

## 7. Перед записью
- [ ] Режим «Не беспокоить», полный заряд, Wi-Fi.
- [ ] Одна тема на все дубли (светлая или тёмная).
- [ ] Чат для съёмки — постановочный (второй аккаунт или друг с согласием), без старой переписки сверху.
- [ ] «Learned from you» почищен от старых личных сообщений.
- [ ] В «Стилях» карточки аудиторий показывают твои настоящие сообщения в пузырях (пример: «норм / заезжали…»): в монтаже заблюрь их или не задерживай на них кадр.
- [ ] Сервер жив: в чате любой запрос отвечает за 3–10 с. Первый запрос после паузы может быть дольше (просыпается).
